# pvz-boonie-bears

《植物大战僵尸》式路线塔防 × 《熊出没》多世界剧情同人项目。

## 当前定位

核心方向：

- PVZ 式路线塔防
- 《熊出没》动画世界/时期推进
- 角色同类合成升级
- 指定跨角色融合
- 人物关系与羁绊解锁
- 每个世界独有玩法机制
- Q 版夸张搞笑演出

当前阶段：**产品定义 + 研究 + 技术 PoC 准备**。

暂不进行大规模正式开发。

## 第一阶段目标

完成一个可完整游玩的 World 01 Vertical Slice：

- 10 关
- 8 名可用角色
- 6 种敌人
- 1 Boss
- 同角色升级
- 少量跨角色融合
- 1 种以上世界机制
- 基础剧情与完整 UI 流程
