# Research

本目录存放 Work + Sol、GPT Chat、Codex 或其他 Agent 的独立研究结论。

## 规则

1. 研究结论必须写证据、来源、限制和推荐理由。
2. 不因为某个 Agent 推荐某方案就自动成为架构或产品决定。
3. 最终批准内容统一记录到 `docs/decisions.md`。
4. 对同一重大问题允许多个独立研究结果并存，便于横向比较。
5. GitHub 项目研究必须记录 License、维护状态和复用方式。
6. 熊出没时间线/角色资料优先使用官方或高可信来源；粉丝资料只能作为线索，不应单独作为最终事实依据。
7. 第三方图片、字体、音乐、音效和代码必须分别核验授权。

建议文件命名：

```text
YYYY-MM-DD-主题-研究者.md
```

例如：

```text
2026-08-23-boonie-bears-world-timeline-work-sol.md
2026-08-23-fusion-system-codex-poc.md
```
