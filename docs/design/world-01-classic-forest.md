# World 01｜经典狗熊岭 / 早期守林冲突

日期：2026-08-23

状态：产品负责人已接受主体方案；肥波阵营按官方资料修正；第 8 名友方可用角色暂不强行指定。

## 世界定位

World 01 对应《熊出没》早期“熊大、熊二守护森林 vs. 伐木工光头强”的关系阶段。

本世界不逐集复刻动画，而是在早期关系与环境设定下编写一条原创 10 关小剧情。

核心冲突：

```text
李老板催光头强交木材
→ 光头强不断尝试进入森林伐木
→ 熊大组织森林伙伴防守
→ 双方不断升级手段
→ 光头强驾驶大型伐木设备发起总攻
```

World 01 结束时光头强仍是对手，不提前推进到后期“熊强”稳定合作关系。

## 角色阵营

### 已定友方可用角色

1. 熊大：中程主力 / 投石 / 稳定输出。
2. 熊二：前排坦克 / 扛伤 / 拍击 / 击退。
3. 蹦蹦：资源型 / 生产或搬运森林物资。
4. 萝卜头：地下伏击 / 单格控制 / 路线互动。
5. 吉吉：指挥辅助 / 节奏增益。
6. 毛毛：快速执行 / 连击 / 与吉吉联动。
7. 涂涂：多路线侦察与支援。

### 第 8 名友方可用角色

暂不强塞后续时期角色。

在核验经典阶段可用角色后再定第 8 人。原则：不能为了凑 8 人把明显属于《环球大冒险》、探险期、电影或更晚时期的角色提前塞进 World 01。

### 肥波

肥波不属于 World 01 友方卡池，改为光头强一侧的角色/支援单位。

官方央视资料可确认：

- 《熊出没之春日对对碰》第 9 集简介写明“光头强带着肥波支起一个陷阱”。
- 《熊出没之夏日连连看》第 30 集简介直接称肥波为“光头强的宠物猫”。
- 《熊出没之春日对对碰》第 45 集简介写明肥波“决定暗中帮助光头强”。

因此本项目早期阶段不把肥波写成熊大熊二一方的常驻友军。

## 同角色升级

World 01 首版固定为三级：

```text
I → II → III
```

原则：每一级优先改变行为、节奏、范围、控制或视觉表现，不只做百分比数值提升。

示例：

### 熊大

- I：单次投石。
- II：快速两连投。
- III：两连投 + 周期性巨石，小范围伤害并轻击退。

### 熊二

- I：承伤 + 近战拍击。
- II：连续拍击 + 受击后反击。
- III：周期性震地，对前方小范围击退。

### 蹦蹦

- I：基础资源产出。
- II：提高产出频率。
- III：周期性产出大份资源。

具体数值留给灰盒 PoC。

## 第一批跨角色融合

World 01 只做两组高质量固定配方。

### 熊大 + 熊二 → 兄弟阵线

- 熊二站前方承伤、拍击。
- 熊大站后方持续投石。
- 熊二连续受击后可触发一次“递石”协同，熊大立刻发动重击。
- 机会成本：两张卡被压到一个格/一条路线，失去横向覆盖。

### 吉吉 + 毛毛 → 猴王连携

- 吉吉发出号令。
- 毛毛立刻追加执行。
- 周期性为附近角色提供短暂节奏增益。
- 设计目标：偏辅助/节奏，不与兄弟阵线争同一用途。

## 资源

World 01 首版采用单资源。

暂定显示名：`森林物资`。

用于：

- 部署角色；
- 同角色升级；
- 固定跨角色融合。

暂不增加第二种“友情/默契”资源。若灰盒测试证明单资源无法抑制融合滚雪球，再评估双资源。

## 棋盘

- 固定 5 条路线。
- 列数必须参数化，程序不得写死 9 列。
- 视觉与第一轮关卡设计按 5×9 作为默认参考。

## 世界专属机制：伐木标记

部分关卡存在被光头强标记或计划砍伐的树木。

规则候选：

- 树木占用部分格子；
- 玩家不能在树木格部署普通角色；
- 特定伐木设备优先攻击目标树；
- 部分关卡要求至少保护 N 棵树；
- Boss 最终阶段会直接威胁被标记目标。

目的：让“保护森林”进入胜负条件，而不是只作为背景叙事。

## 6 种普通/精英敌人

这些是本项目原创的 Q 版伐木机关，不宣称为动画原作机器。

1. 木料小推车：标准基础单位。
2. 疯跑电锯车：低耐久、高移动速度。
3. 铁皮伐木车：正面高防御。
4. 重载搬木车：缓慢、高耐久。
5. 弹簧越障车：第一次接触前排时越过一格。
6. 捕捉网机器：远距离短暂限制一个角色行动。

敌人差异优先依靠行为，而不是纯粹加血。

## 路线容错机关

每条路线左侧设置一次性“熊大滚石机关”。

敌人第一次突破该路线森林警戒线时：

```text
巨石启动
→ 沿路线向右滚动
→ 清理该路线敌人
→ 机关报废
```

作用类似单路一次性保险，但视觉与世界设定采用本项目自己的表现。

## Boss：光头强

### 第一阶段：强哥亲自上阵

- 在战场右侧活动；
- 投放工具箱/小机关；
- 偶尔切换路线；
- 重点训练玩家观察 Boss 行为和预警。

### 第二阶段：大型伐木车

- 获得前方护甲；
- 周期性冲撞；
- 可撞退当前路线最前方角色；
- 冲撞前必须有明显预警。

### 第三阶段：李老板来电话

- 攻击/召唤节奏提升；
- 同时召唤普通机关；
- 开始攻击被“伐木标记”的树；
- 玩家必须同时防线、保目标、打 Boss。

结尾采用夸张喜剧失败演出，但不让熊强在本世界直接和解。

## World 01 核心验证问题

1. 普通铺场本身是否好玩？
2. 同角色升级是否会退化成“见到就合”？
3. 跨角色融合是否有真实的机会成本和不融合理由？
4. 10 关结束后，玩家是否仍愿意进入下一个世界？
